# Music-Player-Using-JavaScript🎵 Music Player Web Application
A responsive and interactive Music Player Web Application built using HTML, CSS, and JavaScript. This project demonstrates audio control functionality along with a modern and user-friendly interface.
📌 Project Objective
The goal of this project is to build a functional music player that allows users to play, pause, and navigate through songs with a smooth and engaging UI experience.
⚙️ Features
▶️ Play, Pause, Next, and Previous song controls
🎧 Display of song title and artist name
⏱️ Duration tracking and real-time progress bar
🔊 Volume control for better user experience
📱 Fully responsive design for all devices
🌟 Bonus Features
📃 Playlist support for multiple songs
🔁 Autoplay functionality for continuous music
🎨 Smooth animations and modern UI design
🛠️ Technologies Used
HTML5 – Structure of the music player
CSS3 – Styling and responsive UI design
JavaScript – Audio control and functionality
💡 Learning Outcome
This project helped me improve my skills in:
JavaScript DOM manipulation
Working with HTML5 Audio API
Event handling and UI interactivity
Responsive front-end development
🚀 Future Improvements
Shuffle and repeat modes
Song search functionality
Online streaming support
